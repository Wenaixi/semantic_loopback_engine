# MaiBot 语义回环调度与反思引擎 (semantic_loopback_engine)

为 MaiBot 打造的语义闭环认知调度引擎。通过维护多轮对话的上下文意图张量，对大模型的历史生成进行语义回环反思与质量评分，抑制幻觉并提升长期对话的一致性与逻辑严密性。

## 核心设计理念

1. 意图锚定：在每轮对话生成前，抽取出用户的核心语义意图与关键实体约束。
2. 回环校验：将候选回复与意图锚点进行向量相似度反向比对，计算意图偏离度。
3. 自主修正：偏离度超出阈值时，自动触发反思循环（Reflection Loop），提示模型修正生成结果。
4. 记忆沉淀：将经过验证的高质量回复提炼为长期情境记忆，注入后续会话。

## 配置参数详解

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `[plugin].enabled` | bool | `true` | 是否启用语义回环引擎 |
| `[engine].loopback_threshold` | float | `0.75` | 意图吻合度阈值，低于此值触发反思 |
| `[engine].max_reflection_rounds` | int | `2` | 单轮消息最多允许反思迭代的次数 |
| `[engine].task_name` | string | `"utils"` | 宿主模型任务名（已适配 MaiBot 1.2.5 规范） |
